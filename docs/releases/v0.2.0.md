# Modelith Plugin SDK 0.2.0

The TypeScript package has a new name and is now on npm, and the contract gains the types Modelith uses to let
AI clients read and write a model.

TypeScript のパッケージの名前が変わり、npm から入れられるようになりました。AI のクライアントがモデルを読み書きするための型も入りました。

## Breaking: the TypeScript package is now `modelith-plugin-sdk`

The npm scope `@modelith` is not available, so the package is renamed from `@modelith/plugin-sdk`.
Install the new package and change the imports:

```sh
npm uninstall @modelith/plugin-sdk
npm install --save-dev modelith-plugin-sdk
```

```diff
-import { connectToHost } from "@modelith/plugin-sdk";
+import { connectToHost } from "modelith-plugin-sdk";
```

Schema imports change the same way (`@modelith/plugin-sdk/schema/*` → `modelith-plugin-sdk/schema/*`).
Nothing else changes for plugins: the manifest, rule files, messages, JSON Schemas, `apiVersion` (`"0"`) and
the Rust crate `modelith-plugin-protocol` are the same as in 0.1.0, so a plugin built with 0.1.0 keeps working.

## Install

```sh
cargo add modelith-plugin-protocol
npm install --save-dev modelith-plugin-sdk
```

The package is also attached to this release as a `.tgz`.

## Added

- **Reading a model**: `ProjectOutline`, `ElementSummary`, `ElementDetail`, `ElementRelation`, `DiagramSummary` and
  `ProblemReport` — what Modelith returns when an AI client (MCP), the app or the server reads or checks a model.
- **Writing a model**: `EditRequest`, `EditProposal` and `FileChange` — an edit is proposed first (a diff, nothing is written)
  and written in a second step.

These are used by Modelith itself, not by plugins. JSON Schemas for all of them are in
[`schema/`](https://github.com/modelith/plugin-sdk/tree/v0.2.0/schema).

The full list of changes is in the [changelog](https://github.com/modelith/plugin-sdk/blob/v0.2.0/CHANGELOG.md).
