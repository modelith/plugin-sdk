# Modelith Plugin SDK 0.1.0

The first release of the contract between [Modelith](https://github.com/modelith/modelith) and its plugins.
With it you can write a plugin that checks a SysML v2 model, adds importers, exporters and commands,
and validate it before you add it to Modelith.

Modelith の最初のプラグイン SDK です。モデルを確かめるルールや、インポート・エクスポート・コマンドを足すプラグインを書き、
Modelith に入れる前に検査できます。

## Install

```sh
cargo add modelith-plugin-protocol
npm install --save-dev https://github.com/modelith/plugin-sdk/releases/download/v0.1.0/modelith-plugin-sdk-0.1.0.tgz
```

The TypeScript package is attached to this release instead of the npm registry. It installs as `@modelith/plugin-sdk`.

## What you can build

- **Rules plugins** — a manifest and YAML files, no code. Check that every requirement is satisfied, every part has ports,
  and more. They run in the browser, in `modelith check` on the command line, and in CI.
- **Browser plugins** — one script in a Web Worker. Talk to Modelith with `connectToHost` to report diagnostics,
  propose text edits, add commands, importers and exporters, read the project's settings and store data.

## What's included

| | |
| --- | --- |
| Rust crate `modelith-plugin-protocol` | The types of the manifest, rule files, messages, `TextEdit` / `Diagnostic` and the registry entry. Only `serde` by default |
| `@modelith/plugin-sdk` | The same types for TypeScript, `connectToHost`, and the `modelith-plugin validate` command |
| [JSON Schemas](https://github.com/modelith/plugin-sdk/tree/v0.1.0/schema) | Generated from the Rust types, for editors and CI |

Check a plugin folder before you add it:

```sh
npx -p https://github.com/modelith/plugin-sdk/releases/download/v0.1.0/modelith-plugin-sdk-0.1.0.tgz modelith-plugin validate path/to/plugin
```

The full list of changes is in the [changelog](https://github.com/modelith/plugin-sdk/blob/v0.1.0/CHANGELOG.md).

## Notes

- This is a pre-1.0 release (`apiVersion` `"0"`). The contract may change in any minor release.
- The manifest and rule files reject unknown fields, so typos are reported instead of ignored.
  Messages ignore unknown fields, so a plugin and Modelith of different versions keep working.
